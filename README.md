# Dating App Prototype

A cross-platform dating application prototype featuring profile matching, real-time messaging, and built-in ad monetization.

---

## 🚀 Features

* **User Authentication:** Secure signup/login with profile setup.
* **Swipe Mechanics:** Interactive card swiping for profile matching.
* **Real-time Messaging:** In-app chat powered by Firebase backend.
* **Ad Monetization:** Integrated Google AdMob banner, interstitial, and rewarded ads.

---

## 🛠️ Tech Stack

* **Frontend:** Flutter / React Native
* **Backend:** Firebase (Authentication, Firestore, Storage)
* **Ad Network:** Google AdMob
